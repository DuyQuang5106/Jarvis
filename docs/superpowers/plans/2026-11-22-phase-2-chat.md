# Phase 2 — Chat hiểu ngữ cảnh: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Owner hỏi một câu ngắn trong Chat và nhận câu trả lời dựa trên trạng thái mới nhất trong database, kèm danh sách nguồn đã dùng; chưa có đề xuất ghi dữ liệu.

**Architecture:** Mỗi lượt chat, server dựng context bằng code thuần (không gọi LLM): tầng 1 là `PortfolioSnapshot` của Phase 1, tầng 2 là chi tiết các area được chọn theo thanh chọn context hoặc khớp theo tên/alias. Context được tuần tự hóa thành JSON đặt trong system prompt. Một async generator `runChatTurn` điều phối lưu tin nhắn, gọi provider và phát sự kiện; route `/api/chat` chuyển các sự kiện đó thành NDJSON cho trình duyệt.

**Tech Stack:** Next.js route handler (stream), Drizzle, Zod, `react-markdown` + `remark-gfm`, Vitest + PGlite, Playwright với mock provider.

**Spec:** `Personal_AI_Workspace_V1.1_Spec.md` — mục 3.2, 6.1, 6.2, 6.4, 7 (flow A, E), 10 (Phase 2), criteria 5, 6, 9, 10. Đọc thêm `docs/superpowers/plans/README.md`.

**Điều kiện bắt đầu:** Phase 1 xong. Báo cáo probe cho thấy `chat` đạt.

## Global Constraints

- Không gọi LLM để phân loại intent hay tóm tắt hội thoại. Lịch sử gửi cho model: 10 tin nhắn gần nhất.
- Bản ghi có `ai_excluded` (area hoặc note) không bao giờ xuất hiện trong payload gửi provider, kể cả gián tiếp qua task, assessment hay log của area đó.
- Model không tự tính ngày: `today`, tuần và mọi `daysLeft` do server tính sẵn.
- Mọi bản ghi trong context mang ID thật.
- Ngân sách context: 32.000 ký tự JSON; vượt thì cắt theo thứ tự đã định, kết quả luôn là JSON hợp lệ.
- Danh sách nguồn (`Dựa trên:`) do server ghi vào `messages.metadata`, không lấy từ câu trả lời của model.
- Provider lỗi: không lưu câu trả lời dở dang, không mất tin nhắn của người dùng, phần còn lại của ứng dụng vẫn dùng được.
- Trần request AI mỗi ngày theo `AI_DAILY_REQUEST_CAP`.
- Log server không chứa nội dung context, nội dung tin nhắn hay API key.
- Tin nhắn chat tối đa 8.000 ký tự. `maxOutputTokens` mỗi lượt: 1500.
- Composer luôn nằm trong vùng nhìn thấy trên iPhone; ô nhập cỡ chữ từ 16px.

## Review Focus

1. Tên tiếng Việt gõ không dấu hoặc khác hoa thường phải khớp; alias ngắn không được khớp nhầm vào giữa từ khác (`SE` trong “research”, `Mobile` trong “automobile”). *(Task 1)*
2. `course_outline` hoặc note rất dài → context vẫn dưới ngân sách và vẫn parse được. *(Task 2)*
3. Nội dung do người dùng nhập chứa `</workspace_state>` hoặc `<` → không phá vỡ khối context. *(Task 2)*
4. Area bị `ai_excluded` nhưng có task sắp đến hạn → task đó không lọt vào `dueTasks` gửi đi. *(Task 2)*
5. Stream đứt giữa chừng → không có tin nhắn assistant dở dang; thử lại không nhân đôi tin nhắn người dùng. *(Task 3)*

### Task 2: Context builder

**Files:**
- Create: `src/server/ai/context-builder.ts`
- Test: `src/server/ai/context-builder.test.ts`

**Interfaces:**
- Consumes: `getPortfolioSnapshot`, `AreaSummary`, `getAreaDetails`, `describeLog`, `matchAreas`, `daysUntil`
- Produces:
  - ```ts
    type ContextScope = { mode: 'auto' | 'all' | 'academic' | 'projects' | 'item'; areaId?: string };
    type ContextRef = { areaId: string; name: string; kind: AreaKind; updatedAt: string };
    type AreaDetailForAi = {
      areaId: string; name: string; kind: AreaKind; summary: string | null; goal: string | null;
      startDate: string | null; deadlineDate: string | null;
      academic: { term: string | null; credits: number | null; targetGrade: string | null; gradingScheme: string | null; examFormat: string | null; courseOutline: string | null } | null;
      project: { role: string | null; collaborators: string | null; scope: string | null; cadence: string | null } | null;
      topics: { id: string; title: string; status: TopicStatus; evidence: string | null }[];
      assessments: { id: string; title: string; dueDate: string | null; daysLeft: number | null; weight: number | null; score: number | null; maxScore: number | null }[];
      milestones: { id: string; title: string; status: MilestoneStatus; targetDate: string | null; acceptanceCriteria: string | null }[];
      blockers: { id: string; title: string; status: BlockerStatus; lastAttempt: string | null; nextAction: string | null; externalDependency: string | null }[];
      tasks: { id: string; title: string; status: TaskStatus; dueDate: string | null; daysLeft: number | null; deadlineType: DeadlineType; estimateMinutes: number | null; blockedReason: string | null; milestoneId: string | null }[];
      notes: { id: string; text: string; updatedAt: string }[];
      recentLogs: { at: string; origin: Origin; title: string; changes: { field: string; before: string | null; after: string | null; summary?: string }[] }[];
    };
    type WorkspaceState = {
      now: { date: string; weekday: string; weekStart: string; weekEnd: string; timezone: string };
      termGoal: string | null;
      areas: Omit<AreaSummary, 'aiExcluded'>[];
      dueTasks: PortfolioSnapshot['dueTasks'];
      upcomingAssessments: PortfolioSnapshot['upcomingAssessments'];
      staleAreaIds: string[];
      details: AreaDetailForAi[];
    };
    type BuiltContext = { state: WorkspaceState; json: string; refs: ContextRef[]; summaryCount: number; truncated: boolean };
    ```
  - `buildContext(db: DbOrTx, input: { message: string; recentUserMessages: string[]; scope: ContextScope; now: Date; maxChars?: number }): Promise<BuiltContext>` — `maxChars` mặc định `32000`
  - `serializeState(state: WorkspaceState): string` — `JSON.stringify` rồi thay mọi `<` bằng `<`

**Quy tắc:**
- **Loại trừ:** bỏ mọi area `aiExcluded` khỏi `areas`, `staleAreaIds`, `details`; bỏ `dueTasks` và `upcomingAssessments` thuộc các area đó; bỏ note `aiExcluded` khỏi `details[].notes`; bỏ khỏi `recentLogs` mọi log của note đang `aiExcluded` **hoặc** có snapshot (before/after) của log mới nhất của note đó mang `aiExcluded: true` — phủ cả note đã xóa và note bị loại sau khi tạo (`describeLog` đã thay nội dung note riêng tư bằng `ghi chú riêng tư`, đây là lớp thứ hai).
- **Chọn area mở rộng chi tiết** (gọi là “đủ điều kiện” khi chưa lưu trữ, không `aiExcluded`, `status` không thuộc `completed`/`on_hold`):
  - `item`: đúng `areaId` nếu nó tồn tại và không `aiExcluded` (không xét status).
  - `academic` / `projects`: mọi area đủ điều kiện của loại đó. `all`: mọi area đủ điều kiện.
  - `auto`: `matchAreas([message, ...recentUserMessages.slice(-3)], areas)` trên các area không `aiExcluded`. Không khớp gì thì `details` rỗng.
- **Nội dung chi tiết:** `tasks` chỉ gồm task chưa `done`; `notes` 10 cái mới nhất; `recentLogs` 20 dòng mới nhất, đổi qua `describeLog`.
- **`refs`:** một phần tử cho mỗi area có trong `details`. `summaryCount`: số phần tử của `state.areas`.
- **Cắt khi `json.length > maxChars`**, áp lần lượt cho tới khi vừa, và đặt `truncated: true`:
  1. Mỗi detail giữ 5 `recentLogs`.
  2. Mỗi detail giữ 3 `notes`, mỗi note cắt còn 500 ký tự kèm `…`.
  3. `courseOutline` cắt còn 2000 ký tự kèm `…`.
  4. Bỏ dần detail từ cuối danh sách (danh sách xếp: area của scope `item` hoặc area khớp `auto` trước, còn lại theo priority cao xuống thấp); `refs` bỏ theo.
  5. Bỏ `recentLogs` và `notes` của các detail còn lại.

import { beforeEach, expect, test } from 'vitest';
import type { Db } from '@/db/client';
import { createTestDb } from '@/db/testing';
import { createArea } from '../services/areas';
import { noteService, taskService, topicService } from '../services/entities';
import { buildContext } from './context-builder';

const NOW = new Date('2026-11-22T03:00:00Z');
const manual = { origin: 'manual' as const };
let db: Db;
beforeEach(async () => { db = await createTestDb(); });
const build = (message: string, scope: any = { mode: 'auto' }, extra: any = {}) =>
  buildContext(db, { message, recentUserMessages: [], scope, now: NOW, ...extra });

test('database trống vẫn cho context hợp lệ', async () => {
  const ctx = await build('Hôm nay nên làm gì?');
  expect(JSON.parse(ctx.json)).toMatchObject({ now: { date: '2026-11-22', weekday: 'Chủ nhật', weekStart: '2026-11-16', weekEnd: '2026-11-22' }, areas: [], details: [] });
  expect(ctx).toMatchObject({ refs: [], summaryCount: 0, truncated: false });

test('auto mở rộng area được nhắc tên; mang ID thật và last updated (criterion 5)', async () => {
  const mob = await createArea(db, { kind: 'academic', name: 'Mobile Programming', aliases: ['Mobile'], status: 'not_started' }, manual);
  await createArea(db, { kind: 'academic', name: 'Database' }, manual);
  const topic = await topicService.create(db, { areaId: mob.id, title: 'Navigation' }, manual);
  const ctx = await build('Mobile Programming đang ở tình trạng nào?');
  expect(ctx.state.areas).toHaveLength(2);
  expect(ctx.state.details.map((d) => d.name)).toEqual(['Mobile Programming']);
  expect(ctx.state.details[0].topics).toEqual([{ id: topic.id, title: 'Navigation', status: 'not_started', evidence: null }]);
  expect(ctx.state.areas.find((a) => a.id === mob.id)).toMatchObject({ status: 'not_started', missing: expect.arrayContaining(['no_assessment_date']) });
  expect(ctx.refs).toEqual([{ areaId: mob.id, name: 'Mobile Programming', kind: 'academic', updatedAt: expect.any(String) }]);
  expect(ctx.summaryCount).toBe(2);
});

test('auto dùng cả ba tin nhắn gần nhất của người dùng', async () => {
  await createArea(db, { kind: 'project', name: 'Question House', aliases: ['QH'] }, manual);
  const ctx = await build('thế còn blocker thì sao?', { mode: 'auto' }, { recentUserMessages: ['QH tuần này thế nào'] });
  expect(ctx.state.details.map((d) => d.name)).toEqual(['Question House']);

test('câu hỏi tổng thể: không mở rộng, vẫn có deadline và dữ liệu thiếu (criterion 9)', async () => {

  const ctx = await build('Tuần này có gì đáng lo?');
  expect(ctx.state.details).toEqual([]);
  expect(ctx.state.dueTasks).toMatchObject([{ title: 'Nộp lab', daysLeft: 2, deadlineType: 'hard' }]);
  expect(ctx.state.areas[0].missing).toEqual(['no_next_action', 'no_topics', 'no_assessment_date']);
});

test('các scope cố định', async () => {
  const course = await createArea(db, { kind: 'academic', name: 'Database', status: 'active' }, manual);
  const proj = await createArea(db, { kind: 'project', name: 'StewieSAT', status: 'active' }, manual);
  const done = await createArea(db, { kind: 'project', name: 'Cũ', status: 'completed' }, manual);

test('ai_excluded không lọt ra ngoài dưới bất kỳ dạng nào', async () => {

    expect(ctx.refs.map((r) => r.areaId)).not.toContain(secret.id);

test('note tạo khi còn gửi được, sau đó bị loại → nội dung cũ không xuất hiện ở đâu trong json', async () => {

  const ctx = await build('Database', { mode: 'all' });
  expect(ctx.state.details.map((d) => d.name)).toEqual(['Database']);
  expect(ctx.json).not.toContain('mật khẩu wifi phòng lab');
  expect(ctx.json).not.toContain('điều đã xóa');

test('task đã done không vào chi tiết', async () => {
  const a = await createArea(db, { kind: 'academic', name: 'Database', status: 'active' }, manual);

test('nội dung quá dài bị cắt nhưng JSON vẫn hợp lệ và dưới ngân sách', async () => {

test('ký tự < trong dữ liệu người dùng được escape', async () => {

- Khối <workspace_state> là trạng thái mới nhất, lấy từ database. Nó luôn được ưu tiên hơn mọi điều đã nói trước đó trong cuộc trò chuyện.

**Luồng `runChatTurn`:**
1. Chuẩn bị tin nhắn người dùng:
   - Không `regenerate`: `message` phải dài 1–8000 ký tự sau trim, nếu không phát `error` “Tin nhắn trống hoặc quá dài.” và dừng. Chưa có `conversationId` thì tạo cuộc chat với `title` là 60 ký tự đầu của `message`. Lưu tin nhắn `user`.

2. Phát `meta`.
3. `countAiRequest`; gặp `AiCapExceededError` thì phát `error` “Đã chạm trần số lượt hỏi AI hôm nay.” và dừng.

5. Gọi `provider.stream` với `[system, ...10 tin nhắn gần nhất trước tin hiện tại, tin user hiện tại]`, `maxOutputTokens: 1500`. Mỗi sự kiện `text` phát lại nguyên dạng.
6. Stream xong: lưu tin nhắn `assistant` với toàn bộ text và `metadata`; cập nhật `conversations.updated_at`; phát `done`.
7. Provider ném lỗi ở bất kỳ lúc nào: **không** lưu tin nhắn assistant; phát `error` “Không gọi được AI. Dữ liệu của bạn không bị ảnh hưởng, có thể thử lại.”; ghi `console.error` chỉ gồm tên lỗi và `status`.
